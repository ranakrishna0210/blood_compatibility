# Blood Group Compatibility System

## About the Project
The Blood Group Compatibility System is a simple Prolog-based project that checks whether a donor's blood group is compatible with a recipient's blood group.

It uses logical facts and rules to determine compatibility between the eight common ABO and Rh blood groups.

## Objectives
- To check blood donation compatibility.
- To understand facts and rules in Prolog.
- To practice logical reasoning and query execution.
- To display clear compatibility results.

## Technologies Used
- **Programming Language:** Prolog
- **Environment:** SWISH Online Prolog

## Blood Groups Supported
- O Negative (O-)
- O Positive (O+)
- A Negative (A-)
- A Positive (A+)
- B Negative (B-)
- B Positive (B+)
- AB Negative (AB-)
- AB Positive (AB+)

## How to Run
1. Open the program in a Prolog environment.
2. Load the Prolog code.
3. Run the query:

   `start.`

4. Enter the donor blood group, such as `o_neg.`
5. Enter the recipient blood group, such as `ab_pos.`
6. View the compatibility result.

## Sample Input
- Donor Blood Group: `o_neg`
- Recipient Blood Group: `ab_pos`

## Sample Output
```text
Blood Donation Compatible!
```

For an incompatible combination, the program displays:

```text
Blood Donation Not Compatible!
```
